# BASystem — 당구 어시스턴트

3쿠션 당구의 **파이브앤하프(다이아몬드) 시스템**으로 수구 경로를 계산해 보여준다.

공식으로 계산하지 않는다. **실제 당구대에서 찍은 영상으로 쿠션 반사를 재서** 그 값으로
공을 굴린다.

최종 목표는 **AI 스마트안경**에서 실시간으로 조준선을 띄우는 것이다.
지금은 그 앞 단계 — 두뇌(계산)와 화면(윈도우·모바일)을 만드는 중이다.

---

## 무엇이 다른가

파이브앤하프는 `수구수 − 1쿠션수 = 3쿠션수` 라는 규칙이다. 규칙대로 그린 경로와
**실제로 공이 가는 경로**는 다르다. 그래서 실제를 쟀다.

국내식 중대에서 노란공 하나로 130샷을 찍어, 쿠션 접점 594개와 입사·반사각 385개를 뽑았다.

**입사각 → 반사각 (실측, 당점 2시30분 3팁)**

| 입사각 | 반사각 | 차이 |
|---|---|---|
| 8.3° | 24.2° | +15.9° |
| 16.7° | 36.9° | +20.2° |
| 27.7° | 46.0° | +18.4° |
| 43.0° | 55.0° | +12.0° |
| 58.3° | 65.8° | +7.5° |
| 72.6° | 78.2° | +5.6° |

정면에 가깝게 칠수록 회전이 많이 먹고, 스치듯 갈수록 거울 반사에 가까워진다.

**채점 결과** — 130샷을 반씩 갈라 한쪽으로 표를 만들고 다른 쪽으로 채점했다.

| 쿠션 | 실측 반사표 | 프레임 거울반사(기존 기하 모델) |
|---|---|---|
| 2쿠션 | **81mm** | 158mm |
| 3쿠션 | **71mm** | 281mm |
| 4쿠션 | **77mm** | 468mm |
| 5쿠션 | **65mm** | 380mm |

쿠션이 늘어도 오차가 쌓이지 않는다. 같은 자리에서 반복해 친 샷들의 흩어짐이 19mm이므로,
남은 70mm 가 앞으로 줄일 몫이다.

## 쓰는 법

### 윈도우

```
pip install pygame-ce numpy opencv-python-headless
python main.py
```

- 색 버튼을 누르고 다이를 누르면 그 자리에 공이 놓인다
- **프레임(나무 레일)을 누르면** 그때 궤적이 생긴다. 끌면 따라온다
- 공을 끌면 궤적도 같이 움직인다
- `+` `−` 는 **현장 보정** — 다이 상태에 따라 각이 길거나 짧게 나올 때 눌러 맞춘다.
  모든 쿠션의 반사각에 같은 양이 걸린다
- `L` 궤적만 지움 / `A` 전부 지움 / `R` 되돌리기

### 모바일 (웹)

```
python -m http.server 8000
```

`http://localhost:8000/mobile/` — 폰에서는 PC 의 IP 로 연다.
윈도우판과 **같은 `data/` 를 읽는다.** 값을 두 벌로 나누지 않는다.

### 영상에서 실측값 뽑기

```
python track.py 영상.mp4 --ball 노란공 --out 저장폴더
```

샷마다 수구 위치 · 1~7쿠션 접점 · 입사각 · 반사각 · 속도를 CSV 와 JSON 으로 뽑고,
샷별 궤적 그림도 저장한다. 다른 당구대에서 새로 재려면 이것만 돌리면 된다.

## 구조

```
core/
  bounce.py       실측 반사표로 공을 굴린다  ← 두뇌
  correction.py   실측 입사→반사 표
  five_half.py    파이브앤하프 번호 읽기 (수구수·1쿠션수·3쿠션수)
  table.py        규격·좌표계·다이아몬드
  orientation.py  네 방향 배치를 좌표 접기로 처리
vision/
  table_detect.py 사진 → 당구대 4코너 → 원근보정
  ball_detect.py  상단뷰 → 공 위치·색
  track.py        영상 → 궤적 → 쿠션 접점 → 각도
data/                     ★ 도메인 값은 전부 여기. 코드에 숫자를 박지 않는다
  measured_bounce.json    실측 반사표
  five_half_numbers.json  레일 번호표
  table_medium.json       국내식 중대 규격
  english.json            당점 (2시30분 3팁 고정)
  vision.json             검출 튜닝값
ui/app.py         윈도우 화면 (pygame)
mobile/index.html 모바일 화면 (웹)
track.py          영상 추출 실행기
main.py           윈도우 실행기
```

## 규격

국내식 중대. 쿠션 날 안쪽 **2448 × 1224 mm**, 프레임 오프셋 90mm, 공 지름 61.5mm.

⚠️ 국제식 대대는 각이 더 길게 나온다. 이 표를 그대로 쓰면 안 된다.
당구대가 바뀌면 `track.py` 로 다시 재면 된다.

## 아직 안 되는 것

- **사진 한 장에서 공 자동 배치** — 당구장 사진 28장 중 코너 27, 공 3색 전부는 13장
- **적구를 맞은 뒤의 경로** — 두께·당점·스트로크에 따른 변화. 촬영부터 다시 해야 한다
- **역산** — 적구 위치를 주면 어디를 칠지 알려주기

---

## 만든 방식

당구 이론은 전부 사용자(500점)가 정하고, 코드는 그 값을 옮기기만 했다.
값은 `data/` 에 분리해 두었으므로 숫자만 고치면 코드를 안 건드리고 튜닝할 수 있다.
